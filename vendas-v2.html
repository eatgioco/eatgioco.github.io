O que este import vai fazer

Cada documento conta para o dia de operação: o que é fechado antes das 5h pertence ao dia anterior. Um dia que o ficheiro cobre por inteiro é substituído; um dia que o ficheiro só toca em parte recebe apenas os documentos novos, sem perder os que já lá estão. Nada é gravado até confirmares.

O que este import gravou

Cada dia do ficheiro é gravado à parte e o mês é recalculado a partir de todos os dias que existem — os deste import e os anteriores. Substituir um dia não toca nos outros.
